# Smart Night Lamp

An Arduino-based automatic night lamp using an LDR sensor.

## Components

- Arduino UNO
- LDR
- LED
- 220 ohm resistor
- 10k ohm resistor
- Breadboard
- Jumper wires

## Working

The LDR detects the surrounding light.

When the environment becomes dark, the Arduino turns ON the LED.

When sufficient light is detected, the LED turns OFF.
